# ⏱ Timery — نسخه ۳.۲.۰

افزونهٔ Chrome (Manifest V3) برای **تایمر، پومودورو، حالت تمرکز و یادآور** که حتی بعد از بستن مرورگر هم کار می‌کند، روی صفحه‌های وب نمایش داده می‌شود و از راه **بله** هم قابل کنترل است.

---

## ✨ قابلیت‌ها

| بخش | توضیح |
|---|---|
| **تایمر** | چند تایمر همزمان با **حلقهٔ پیشرفت**، شروع با «۲۵ دقیقه» یا `1:30`، پیشفرض‌های آماده، مکث/ادامه، حذف |
| **دوام تایمر** | پایان تایمر با `chrome.alarms` — حتی با بسته بودن همهٔ تب‌ها، نوتیفیکیشن + صدا پخش می‌شود |
| **پومودورو** | چرخهٔ تمرکز/استراحت، نمایش جلسات امروز، شروع خودکار استراحت |
| **حالت تمرکز** | مسدودسازی سایت‌های حواس‌پرت با `declarativeNetRequest` (اینستاگرام، یوتیوب، …) |
| **کنترل از بله** | کاربر فقط یوزرنیمش را می‌دهد؛ فرمان‌های `/timer`، `/list`، `/stop`، `/status` از بله اجرا می‌شوند |
| **هویت ربات** | نام و یوزرنیم ربات در تنظیمات نمایش داده می‌شود و دکمهٔ «تست ارسال» باعث می‌شود خودِ ربات پیام معرفی بفرستد |
| **نمایش روی وب** | Overlay چندتایمری، قابل جابه‌جایی، کوچک‌سازی، پنهان‌سازی، شمارش معکوس عنوان تب |
| **کرنومتر** | شروع/توقف/ادامه (بدون از دست رفتن زمان)، ثبت «دور»، ماندگار |
| **یادآور** | تکرار: یک‌بار، روزانه، هفتگی، ماهانه، سالانه + فعال/غیرفعال + «۵ دقیقه دیگر» در اعلان |
| **ابزار تاریخ** | تبدیل شمسی ⇄ میلادی دقیق، محاسبهٔ سن، فاصلهٔ دو تاریخ |
| **همگام‌سازی** | بین دستگاه‌ها با `chrome.storage.sync` |
| **بودجهٔ بصری** | Badge روی آیکون، پوستهٔ روشن/تاریک، Toast، شورتکات کیبورد |

## 🚀 نصب برای کاربر نهایی

1. `chrome://extensions` → **Developer mode**
2. **Load unpacked** → پوشهٔ پروژه
3. تب **تنظیمات** → بخش **بات بله** → **«ساخت کد اتصال»** → لینک را در بله باز کنید

> **چرا کد اتصال و نه یوزرنیم؟** بله (مثل تلگرام) اجازه نمی‌دهد ربات با `@username` به چت خصوصی پیام بدهد؛
> ربات فقط بعد از اینکه کاربر خودش `/start` بزند `chat_id` عددی را می‌گیرد. کد اتصال همین کار را خودکار می‌کند.
> آدرس سرور و توکن بات داخل پروژه و روی Cloudflare تنظیم شده‌اند.

### میانبرهای کیبورد

| کلید | کار |
|---|---|
| `Ctrl+Shift+5` | تایمر سریع ۵ دقیقه |
| `Ctrl+Shift+2` | تایمر سریع ۲۵ دقیقه (پومودورو) |

## ⭐ راه‌اندازی بات بله (فقط توسط توسعه‌دهنده)

معماری **«توکن پشت توکن»**: داخل افزونه فقط یک *کلید ساختگی* است و توکن واقعی ربات پشت Cloudflare می‌ماند.

```js
// js/config.js
var TIMERY_CONFIG = {
  baleKey: 'TIMERY-A1B2C3',     // کلید ساختگی (نه توکن واقعی!)
  proxyUrl: 'https://timery-bale-relay.XXX.workers.dev',
  botUsername: '@timery_bot',
  ...
};
```

```bash
cd worker
wrangler kv namespace create CHATS        # الزامی: نگهداری نگاشت یوزرنیم → chat_id
wrangler secret put BALE_TOKEN           # توکن واقعی ربات (Secret)
wrangler secret put TIMERY_KEYS          # کلیدهای ساختگی: TIMERY-A1B2C3,TIMERY-D4E5F6
wrangler secret put WEBHOOK_SECRET       # رمز مسیر webhook
wrangler deploy
```

سپس یک‌بار webhook را ثبت کنید (بدون آن، سرور نمی‌فهمد کاربر `/start` زده):

```bash
curl -X POST "https://timery-bale-relay.XXX.workers.dev/admin/webhook" \
  -H "x-timery-key: TIMERY-A1B2C3" -d '{}'
```

**کاربر نهایی فقط یک دکمه می‌زند:** «ساخت کد اتصال» → لینک `ble.ir/<bot>?start=CODE` باز می‌شود →
بله خودش `/start CODE` را می‌فرستد → `chat_id` عددی ذخیره می‌شود و از آن به بعد همهٔ ارسال‌ها پایدارند.

جزئیات کامل: [`worker/README.md`](worker/README.md)

## 🤖 کنترل از بله

کاربر در گفتگوی بات می‌نویسد:

| فرمان | کار |
|---|---|
| `/timer 10m` | تایمر ۱۰ دقیقه‌ای در مرورگر |
| `/list` | لیست تایمرهای فعال |
| `/stop` | توقف همهٔ تایمرها |
| `/status` | وضعیت کامل |
| `/remind 9:00 متن` | ساخت یادآور |

افزونه هر دقیقه فرمان‌ها را از Worker می‌گیرد و پاسخ را روی بله می‌فرستد.

## 🔐 ملاحظات امنیتی

- توکن بات بله **هرگز** داخل افزونه نیست؛ فقط به‌صورت Secret در Cloudflare.
- حالت «ذخیرهٔ توکن در مرورگر» عمداً وجود ندارد.
- Worker محدودیت نرخ دارد (۶۰ پیام در ساعت برای هر کاربر).
- فقط کاربرانی پیام می‌گیرند که خودشان به بات پیام داده‌اند.
